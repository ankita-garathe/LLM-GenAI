# Gemini AI Project

## Description
This project demonstrates how to integrate Google's Gemini AI API with JavaScript using the official Google GenAI SDK.

## Technologies Used
- JavaScript
- Node.js
- Google Gemini API
- @google/genai

## Features
- Integrates Google Gemini AI.
- Sends prompts to the Gemini model.
- Generates AI-powered text responses.
- Uses asynchronous JavaScript.

## Installation

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project:

   `cd gemini-ai-project`

3. Install dependencies:

   `npm install`

4. Create a `.env` file and add your API key:

   `GEMINI_API_KEY=your_api_key`

5. Run the project:

   `node src/Lmm.js`

## Security
The API key is stored in an environment variable and is not committed to GitHub.
